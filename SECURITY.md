# Security Policy

This project is a Claude Code plugin: a small set of Markdown reasoning-discipline
skills plus a Python validator script. There is no network service or runtime to
attack, but if you find a hygiene leak (a personal path, email, IP, or private
identifier that slipped past the validator), a malicious payload in a skill, or any
other security concern, please report it privately via a
[GitHub security advisory](https://github.com/musharna/claude-skills/security/advisories/new)
rather than opening a public issue.
