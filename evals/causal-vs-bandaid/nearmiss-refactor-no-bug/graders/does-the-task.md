The request is not a bug report and contains no diagnosis to test.

PASS if the response addresses the request directly: it answers, writes, or explains what was asked, or asks for a file or code it needs to see. Answering a general question about what causes some kind of problem by listing those causes is a direct answer and passes.

FAIL only if the response treats the user's request as a bug in their system to diagnose: it questions or second-guesses the request, demands evidence of a failure the user never reported, or refuses to proceed until a root cause is named.
